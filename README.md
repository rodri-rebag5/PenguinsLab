Description:
Penguin's Lab is an educational platform that offers a variety of online courses that aim to educate and teach business professionals different technological skills and tools to help them improve their work and develop a new way of working. This idea came while talking with my girlfriend about different business opportunities, and she suggested that this type of platform for people in Peru that sometimes don't have access to these types of tools could be a game changer. Using Python, Flask, SQL, HTML and CSS I decided to make a prototype of the website we would like to offer and see in the market.

The first part of the code is the python code, "app.py". In this document, Flask and SQL are implemented to link the code with and SQL table and to allow the usage of Flask for a better website implementation. This code is very simple, as it uses "GET" and "POST" methods to reroute the webpage into the correct HTML file according to what the user is imputing. Given it's a website focused on online courses, the main actions users have to complete are getting from one screen to another, registering on the webpage and being able to view the videos available for each course. The Python code will return whichever part of the webpage the user has requested, and in the case of the courses, it will generate a course site corresponding to what the user requested. This means that it doesn't matter how many courses are added or are available, the code will generate a new HTML based on the course selected. Finally, the additional functions file "additional_functions.py" contains the required function to check if the user is logged in. This was borrowed from CS50 "Finance".

The HTML files are very simple, as they are mainly focused on displaying the available options for the users. There are HTML files for logging in, registering, viewing your profile and accessing all of the courses available. Depending on whether you are a registered user or not, an additional site containing the courses you as a user are registered in will be available. All of this is possible with the use of Jinja. This is because Jinja allows variables of lists to be displayed in the website, and is very useful to generate webpages based on each user's information. Views such as the enrolled courses or the profile information can be achieved through Jinja, given that first the information is retrieved first with SQL commands in Python to then pass that information to the HTML file with Jinja. The HTML is simple and organizes all the information displayed in tables to simplify the distribution of the text. The main part of the HTML is the course view where you can see the video tutorials. Because this isn't a real platform, I had to use videos available on YouTube embedded with an iframe tag. Of course, in a real situation, these would be videos stored in the folder project. It's important to note that given that I'm not a teacher or a professional educator, I don't have my personal teaching videos regarding the topics mentioned in the page. This means that I had to use videos sourced from YouTube by different creators that actually give courses, just for the sake of showing how the page would work.

The CSS file is quite simple, and it just gives style to the content displayed in the HTML. It gives buttons and text certain colors and fonts respectively, and allowed me to design tables to ensure the website looks like an actual courses site. It gave me control to center texts, change paddings and most importantly, allowed for a cool implementation of an image slider, which I obtained the information on how to do it here: "https://www.youtube.com/watch?v=McPdzhLRzCg&ab_channel=Skillthrive". It was something I saw on other sites and wanted to replicate, with images that showed some of the courses I would like to offer.

Finally, the SQL part. In the "create.sql" file I added commands that was going to execute in the sqlite3 terminal, as I just wanted to copy and paste instead of writing it directly in the terminal. "penguinslab.db" is a database that contains all the tables necessary for the correct function of the website. In it there are 3 tables: a users table that stores user information, a courses table that stores the courses information, and a user courses that relates both tables, storing which courses each user has enrolled in and has available. All contents are accessed and modified in the Python script, therefore there is no need to access the DB from the terminal.

Some of the design decisions I had to make throughout the project involve mainly looks and the things I had to choose to be displayed on the website. Firts and foremost, I am not an expert on web design and programming, so I try to use most of the things I know and intuition to try and design the website. It's because of this that I kept the design very simple, and focused on the webpage actually working error free. It may not have many features, but what I wanted the most was that everything worked smoothly and served as a basis for a future design that could actually lead to a real and feature-rich experience.
